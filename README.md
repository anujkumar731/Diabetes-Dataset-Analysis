# Diabetes Dataset Analysis

## Project Overview
This project explores the Pima Indians Diabetes Dataset using Python. The goal is to understand the dataset, identify patterns, and explore relationships between different health-related features and diabetes outcomes.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Steps
1. Imported required Python libraries.
2. Loaded and explored the dataset.
3. Checked missing values and duplicate records.
4. Cleaned invalid zero values.
5. Analyzed diabetes outcome distribution.
6. Visualized feature distributions.
7. Created a correlation heatmap.
8. Compared Glucose, BMI, and Age across diabetes outcomes.

## Dataset
The dataset contains 768 records and 8 input features, along with an Outcome column.

## Key Learning
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Correlation analysis
- Using Pandas and NumPy
